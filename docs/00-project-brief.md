# Onpilot — Project Brief

## Qué es Onpilot

Onpilot es un SaaS multi-tenant para negocios locales de servicios como centros de estética, fisioterapia, psicología, nutrición, dental, fitness y sectores similares.

El objetivo de Onpilot es ayudar al profesional a gestionar su negocio desde una única plataforma, automatizando tareas repetitivas como agenda, recordatorios, respuestas por WhatsApp, reactivación de clientes, publicación en redes y análisis de métricas.

## Propuesta de valor

> El negocio funciona en piloto automático mientras el profesional se dedica a lo que sabe hacer.

Onpilot debe transmitir siempre la idea de piloto automático, simplicidad, control y ahorro de tiempo.

## Módulos principales

### H1 — Agenda y clientes

Módulo base del sistema.

Incluye:

- Gestión de citas.
- Clientes.
- Fichas.
- Historial.
- Cobros.
- Cierre de caja.
- Servicios.
- Descuentos VIP.
- Importación de clientes.

H1 es la fuente de verdad del sistema. Desde aquí salen los datos para WhatsApp, dashboard, reactivación y métricas.

### H2 — WhatsApp automático

Módulo core del producto junto con H1.

Incluye:

- Bot 24/7.
- Respuestas automáticas.
- Gestión de citas desde WhatsApp.
- Confirmaciones.
- Cancelaciones.
- Recordatorios.
- Reactivación de clientes.
- Escalado a humano.

El bot debe conectarse siempre con la agenda real del negocio.

### H4 — Contenido para redes

Módulo de creación y publicación de contenido.

Incluye:

- Generación de captions con IA.
- Publicación en Instagram.
- Publicación en Facebook.
- Publicación en TikTok.
- Estados de WhatsApp.
- Calendario de publicaciones.
- Ideas de contenido por sector.

Para MVP se podrá usar una API unificada como Zernio. Más adelante se valorarán integraciones directas.

### H5 — Panel de control

Módulo de métricas e inteligencia de negocio.

Incluye:

- Facturación.
- Citas realizadas.
- Ticket medio.
- Clientes nuevos.
- Clientes recurrentes.
- Retención.
- Top servicios.
- Alertas automáticas.
- Métricas del bot.
- Métricas de publicaciones.

## Modelo de negocio

Onpilot se vende por herramientas contratadas:

- H1 Agenda y clientes.
- H2 WhatsApp automático.
- H4 Contenido para redes.
- H5 Panel de control.

Cada negocio puede tener activadas unas herramientas u otras.

El backoffice interno de Onpilot controla qué módulos tiene activos cada cliente.

## Usuarios principales

### Equipo Onpilot

Gestiona:

- Clientes SaaS.
- Herramientas activas.
- MRR.
- Onboarding.
- Soporte.
- Calidad del bot.
- Conectores.
- Facturación.

### Negocio cliente

Gestiona:

- Agenda.
- Clientes.
- Cobros.
- Conversaciones.
- Publicaciones.
- Métricas.

### Cliente final del negocio

Interactúa principalmente por WhatsApp para:

- Pedir información.
- Agendar citas.
- Confirmar citas.
- Cancelar citas.
- Resolver dudas básicas.

## Principios del producto

- Simplicidad antes que complejidad.
- Automatización con control humano.
- El profesional siempre puede tomar el control.
- El bot nunca debe dar consejo médico.
- Los datos de cada negocio deben estar aislados.
- Primero valor real, luego integraciones avanzadas.
- Construir por fases.
- No sobreingenierizar el MVP.
